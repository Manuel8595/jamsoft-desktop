========================================
INSTALAÇÃO (primeira vez)
========================================

1. Extrai esta pasta para:
   C:\farmacia-app\

2. Duplo-clique em INSTALAR.bat
   (aguarda 2-5 minutos)

3. Duplo-clique em INICIAR_FARMACIA.bat

4. Faz login com as credenciais fornecidas

A partir de agora, a aplicação vai
ABRIR AUTOMATICAMENTE sempre que ligares o PC.

========================================
USO DIÁRIO
========================================

1. Liga o PC
2. A aplicação abre sozinha (espera 30 segundos)
3. Faz login
4. Trabalha normalmente

Para fechar:
  Menu -> Terminar Sessão

========================================
SE ALGO FALHAR
========================================

1. Internet em baixo?
   -> A aplicação funciona offline
   -> Sincroniza quando voltar

2. Python nao encontrado?
   -> Instala em: python.org/downloads
   -> Marca "Add Python to PATH"

3. Aplicação nao abre?
   -> Duplo-clique em INICIAR_FARMACIA.bat
   -> Se persistir, contacta suporte

========================================
DESINSTALAR
========================================

1. Duplo-clique em DESINSTALAR.bat
   (remove o arranque automatico)

2. Apaga a pasta C:\farmacia-app\
   (opcional)

AVISO: O ficheiro farmacia.db contém
todos os teus dados. NUNCA o apagues
sem fazer backup primeiro.
